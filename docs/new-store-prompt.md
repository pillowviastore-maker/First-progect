## 1. ПРАВИЛА

**Мова.** Спілкування — {{мова користувача}}. Усі тексти сайту — мовою ринку, нативно, коротко, без канцеляриту.

**Чесність і закон (FTC, GDPR/CCPA, Meta Ads Policy):**
- Жодних вигаданих відгуків, рейтингів, лічильників клієнтів, експертів, лікарів, сертифікатів, адрес, телефонів.
- Жодних фальшивих «старих» цін, таймерів що перезапускаються, «залишилось 3 шт».
- Жодних медичних/лікувальних обіцянок, «до/після», звертань до особистих проблем («Твоя спина болить?»).
- Чужі бренди й логотипи не мають з'являтися на фото/відео.
- Немає доступу до сервісу чи сайту — скажи прямо, не вигадуй результат.

**Безпека.** Ніколи не проси в чат SSN/ITIN, паролі, дані карт чи банку — лише вказуй, де ввести їх у Shopify.

**Процес.**
- Гілка теми = жива тема магазину; кожен пуш одразу на сайті. PR не створювати без запиту.
- Конфлікт із комітами Shopify-редактора: pull → merge → зберегти правки з редактора → перегенерувати шаблони.
- Видалення, зміна цін, юридичні тексти, аудит — спершу нумерований список, дія лише після підтвердження номерів.
- Звіт після етапу: зроблено → що зробити користувачу (точний шлях у Admin) → що перевірити на телефоні.

## 2. АРХІТЕКТУРА

- Тема **Dawn** (остання версія). Власні секції/сніпети з префіксом `{{xx}}-`, свій `assets/{{brand}}.css` і `assets/{{brand}}.js`. Ядро Dawn не правити без потреби.
- Дизайн-токени в CSS-змінних: акцентний колір, червоний для знижок, радіуси, відступи. Mobile-first (390px), десктоп — 1200px контейнер.
- `templates/*.json` і header/footer groups генерує Python-скрипт у `tools/` (тексти, порядок секцій, налаштування — в одному місці). Скрипт зберігає секції застосунків (відгуки тощо) при перегенерації.
- Дані магазину — через Shopify Admin GraphQL: товар, варіанти, медіа, alt, знижки, сторінки, меню, SEO-метаполя, блог.
- Валідація: Shopify theme check (без нових помилок) + Playwright-скріншоти + перевірка кошика через `/cart/add.js` і `/cart.js`.

## 3. ЕТАПИ

### 3.1 Бренд
Логотип (SVG + PNG, світлий/темний), фавікон 512px (читабельний у 16px), аватар соцмереж 320×320, обкладинка Facebook 1640×624 зі слоганом-вигодою. Все в `brand/`.

### 3.2 Товар і ціноутворення
- Назва (бренд + ключ пошуку), опис, варіанти з окремим фото для кожного.
- Ціна закінчується на .99, маржа ≥ 60% після собівартості й доставки.
- **Бандли за кількістю:** 1 шт / 2 шт (≈ −30%, бейдж «Most popular») / 3 шт (найвигідніше, «Buy 2 Get 1 Free» або −40%). Для 2+ шт — вибір варіанту для кожної штуки окремо. Знижки — автоматичні в Shopify; суми в кошику мають збігатися з показаними.

### 3.3 Сторінка товару (головна точка продажу)
Порядок секцій:
1. Галерея + назва + рейтинг (з застосунку відгуків) + ціна з економією
2. Бандли → Add to cart → **видимі кнопки експрес-оплати** (Shop Pay / Apple Pay / Google Pay; працюють і з мульти-варіантним бандлом)
3. Доставка/повернення в один рядок, 3–4 питання FAQ-акордеоном
4. Проблема → рішення (акордеон або картки)
5. Гарантія
6. «Як це працює» — 3 кроки з відео/фото
7. Сценарії використання
8. Порівняльна таблиця «Ми vs звичайний аналог»
9. FAQ
10. Фото-стрічка
11. Відгуки (згорнуті під «See all N reviews»)

UX: липка Add to cart на мобільному, анімація появи при скролі, компактні відступи, жодного горизонтального скролу, фото ≤ 200 КБ, lazy-load.

### 3.4 Кошик
Плашка апсейлу на наступний бандл з кнопкою «Upgrade now» (сама додає потрібну кількість) і прогрес-баром; після досягнення — підтвердження «✓ Deal applied». Іконки довіри й оплат під Checkout.

### 3.5 Головна, шапка, футер
Головна — лендинг товару (hero + вигоди + відгуки + CTA). Банер оголошень лише з реальними акціями. Логотип веде на товар. Футер: Contact, Track order, FAQ, блог, усі політики, іконки оплат.

### 3.6 Сторінки й політики
Refund, Shipping, Privacy, Terms (за реальними умовами), Contact (email + форма, без вигаданої адреси), FAQ, Track order (окремий шаблон сторінки з віджетом трекінгу).

### 3.7 Застосунки й налаштування (налаштувати або дати покрокову інструкцію)
- Dropshipping (DSers): прив'язка варіантів, авто-передача трек-номерів.
- Відгуки (Judge.me): стиль сайту, лише реальні відгуки.
- Оплата: Shopify Payments + Shop Pay, тестове замовлення в test mode.
- Meta (піксель, верифікація домену), Google & YouTube, Search Console.
- Домен, пошта відправника, податки, зони доставки.

### 3.8 SEO
SEO title/description для товару, головної, сторінок; alt усіх зображень; блог із 3 статтями під інформаційні запити ніші з посиланням на товар; посилання на блог у футері; верифікація Search Console.

### 3.9 Рекламні матеріали
- Відео 9:16, 15–30 с: хук → проблема → рішення → CTA; великі субтитри; без медичних обіцянок і чужих брендів.
- Музика — лише з комерційною ліцензією для реклами; вказати назву, автора, посилання, умови.
- Перший пост і 3 варіанти рекламного тексту.

### 3.10 Аудит перед запуском
Нумерований список із пріоритетами (критично / важливо / бажано): юридичні ризики, неправдиві заяви, ціни й знижки в кошику, checkout, мобільна верстка, швидкість, SEO, політики, пошта, трекінг. Виправлення — лише підтверджених пунктів.
